## Date and scope corrections

- `2610.28416` is Code2Video-Compass; Mallea is `2610.21283`.
- EdenLive is verified available by 2026-10-26; this audit did not establish the previously discussed exact October 18 release date.
- StreamRender-H3 was available by October 12, as established by its official repository issue; this is an upper bound on first release. Its current page may describe later updates.
- Mundo is cited as an official project with a dated October 23 author announcement; no standalone paper identifier is invented.
- AW-0 uses code for skills/control, while learned experts predict video/actions. SolarRenderer and EdenLive are rendering-interface support. These are not automatically executable dynamics or next-observation-code methods.
- Source review is metadata/abstract or selected full text, not independent experimental reproduction.
