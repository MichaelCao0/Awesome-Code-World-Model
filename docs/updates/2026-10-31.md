# Update — 2026-10-31

This pass searches arXiv submissions from **2026-10-13 through 2026-10-29** with queries covering executable worlds, world programs, coding agents, simulator construction, programmatic 3D, and persistent state. No relevant arXiv submission dated 2026-10-30 or 2026-10-31 appeared in the queried feed; the catalogue cutoff is therefore **2026-10-29**. Newly added records are abstract-level reviews unless a later note says otherwise.

The inclusion boundary is now explicit: a paper enters one of the three public families only when code carries executable dynamics, persistent world state, world rules, simulator extensions, or editable 3D-world construction. Generic video world models, renderers, benchmarks, datasets, and related surveys remain searchable in the master list without being forced into a family.

## Reclassification

The three families are now split by **how much of the world the code carries**: WorldCoder-type carries state and rules only; Code-as-World-type carries state and rules over a whitebox/proxy world rendered by a generative model; VibeWorlding-type writes the full 3D world itself, with static scenes included for now. GUI world models form a named unassigned group (`unassigned_group: "gui"`). The [three-family guide](../coarse-taxonomy.md) gives the placement order.

**Counts after reclassification:** 38 WorldCoder-type · 22 Code-as-World-type · 35 VibeWorlding-type · 37 unassigned (16 in the GUI group). The counts in the section above describe the state before this change.
